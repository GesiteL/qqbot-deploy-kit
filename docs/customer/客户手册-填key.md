# 客户手册：填写 / 更换模型 Key（三步）

适用版本：v0.2.0 安装器 + AstrBot 4.29.3 + NapCat v4.18.41
适用对象：客户本人。全程只操作自己这台电脑，不需要把 Key 发给任何人。

> **v0.2 安装器已经在安装时问过中转站地址和 Key，并自动写入了。**
> 本文只用于两种情况：安装时跳过了，或者以后要换 Key。
> 不知道 AstrBot 面板密码？不用找：直接重新运行 `安装.bat`，在问答里粘贴新 Key 就行。
> 前置：已经双击 `<安装目录>\启动.bat`，并等到窗口出现 `AstrBot started.`。
> 登录账号：`astrbot`；初始密码由交付人员当面告知（首次登录后请立即修改）。
> 路径约定：`<安装目录>` 默认 `C:\QQBot`；如果安装时选了别的盘，以 `安装信息.txt` 为准。

```
第 1 步 打开面板            第 2 步 找到模型            第 3 步 粘贴 Key

└─────────────────────┘   └─────────────────────┘   └─────────────────────┘
```

## 第 1 步：打开本地面板并登录

1. 在本机浏览器地址栏输入：`http://127.0.0.1:6185`
2. 必须用 `127.0.0.1`，不要用局域网 IP 或 `0.0.0.0`（服务只监听本机）。
3. 用户名 `astrbot`，输入交付人员提供的初始密码；如提示改密码，就改成只有自己知道的新密码。

## 第 2 步：进入模型设置

1. 点击左侧「服务提供商」（模型 / Provider）。
2. 找到 **API 地址为 `<中转站地址>`** 的 OpenAI 兼容条目（地址以所购站点提供地址为准；
   模型名显示为 `custom/【草莓按次-0.03】gemini-3.8-flash-high`）。
   如果界面把「提供商」和「模型」分成两栏：Key 填在提供商条目，模型条目保持已选中就行。
3. 点击该条目的「编辑」。**API 地址**：`<中转站地址>`（以所购站点提供地址为准；
   框里地址和站点给的不一致，就改成站点给的）。**模型名已预填**：
   `custom/【草莓按次-0.03】gemini-3.8-flash-high`，不要改。

## 第 3 步：粘贴 Key 并保存

1. 在「API Key」输入框里清空旧内容，粘贴你从模型服务商处拿到的新 Key。
2. 点击「保存」。
3. 回到对话页发一句「你好」：能正常回复就是配置成功；如果提示 401/403，检查 Key 是否完整、额度是否可用。
   （也可以重新运行 `安装.bat`，在问答里粘贴新 Key；安装器会保留其它数据。）

## 注意事项

- Key 只保存在本机 `<安装目录>\runtime\astrbot\data\cmd_config.json` 里，不会上传给交付方。
- 不要把 Key 发到微信群、文档或截图里；截图前先遮住 Key。
- 不要随便改 API 地址（以所购站点提供的为准）、模型名和端口；误改了就对这本手册恢复。
- 面板只允许本机访问；不要把 6185/3001 端口映射到公网。
- 要换 Key：重复第 2～3 步，清空旧 Key 后粘贴新 Key 保存即可，不用重装；
  也可以重新运行 `安装.bat` 让安装器代填。

## 启动与关闭

- 双击 `<安装目录>\启动.bat`：会最小化启动 NapCat 与 AstrBot，等就绪后自动打开两个本地页面。
- 已经启动时再双击不会重复启动，只会打开页面（防双开）。
- 双击 `<安装目录>\停止.bat` 可关闭全部服务并释放端口。

## 可选：开机自启（不使用注册表或系统服务）

安装器里选「开机自启 = 是」会自动完成，不用手工操作。想手动设置时：

1. 右键 `<安装目录>\启动.bat` →「发送到」→「桌面快捷方式」。
2. 按 `Win+R`，输入 `shell:startup` 回车，把那个快捷方式放进打开的文件夹。
3. 下次登录 Windows 会自动启动；不想要了删掉那个快捷方式就行。
