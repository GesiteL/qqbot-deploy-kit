# 小满 QQ 助手 · 客户使用说明

【截图位 1：解压后的文件夹，里面能看到「安装.bat」】

## 这是什么

小满是住在你电脑里的一个 QQ 聊天助手，会用朋友一样的口气在群里或私聊里跟你聊。
它会自己看时间，偶尔发一条生活说说，也能帮你点歌。
所有聊天记录和设置都留在你自己的电脑里，不会上传给交付方。

## 它能做什么

- 在群里不用 @ 也会接话，短句、像群友，不像客服。
- 发图给它，它先看懂图里是什么，再回你。
- 说「三分钟后提醒我」，到点它会回来找你。
- 每天自己发 1～3 条生活说说，也会给你的说说点赞、评论。
- 想听歌就报歌名，它帮你点。
- 深夜话更少，不会硬撑着讲大道理。

> 下文里的 `<安装目录>` 默认是 `C:\QQBot`；如果你安装时选了别的盘，就是
> `<你选的盘>:\QQBot`。装好后打开 `<安装目录>\安装信息.txt` 也能看到实际路径。

## 第一步：安装

1. 把交付方给你的 **仓库 zip** 解压到一个普通文件夹（不要在压缩包里直接双击）。
2. 双击里面的 **`安装.bat`**。Windows 或杀毒软件要是提示，就选「仍要运行 / 允许」。
3. 黑色窗口会按顺序做检查，然后问你几件事：
   - **装在哪个盘**：直接回车 = C 盘；也可以输入 D/E 等（至少要有 10 GB 空闲）。
   - **扫码**：用手机 QQ **小号**扫黑色 NapCat 窗口或二维码图片里的码，手机上点确认。
   - **中转站地址和模型 Key**：按交付方给你的内容粘贴。Key 输入时会显示在屏幕上，注意周围无人。
   - **管理员 QQ 号**：填你自己的 QQ 号。
   - **白名单群号**：想让机器人在哪些群说话就填哪些，多个用逗号分隔；直接回车 = 先不拉群。
   - **人设**：建议选「是」，加载默认的「小满」。
   - **开机自启**：想要就选「是」，不想要直接回车。
4. 等窗口出现「安装完成」，就可以去群里发一句「在吗」了。

> 不想手动粘贴 Key：在 `安装.bat` 旁边放一个 `key.txt`，第一行写中转站地址，第二行写 Key；
> 安装器会读取并跳过输入。**安装完成后请删除 `key.txt`。**

【截图位 2：黑色安装窗口显示「安装完成」】

## 装完之后

- 双击 `<安装目录>\启动.bat` 启动；已经开着时再双击不会重复启动。
- 双击 `<安装目录>\停止.bat` 关闭。
- 想改 Key / 换管理员 / 加群：重新运行 `安装.bat`，它会保留数据并让你重新填写；也可以按
  《客户手册-填key.md》在 AstrBot 面板里改 Key。
- 想改人设：在 AstrBot 面板（`http://127.0.0.1:6185`）里换；默认人设是小满。

【截图位 3：安装目录里的 启动.bat / 停止.bat / 安装信息.txt】

## 出问题找谁

先看 `<安装目录>\install.log`，把最后几行或整个文件发给交付方（里面没有你的 Key）。
微信 / 电话：________________（交付时填写）

## 安全说明

- 机器人只在本机运行，服务只监听 `127.0.0.1`；不要把 3001/6099/6185 映射到公网。
- 模型 Key 只保存在你自己的电脑里；不要发到群里、截图或文档里。
- 建议用 QQ 小号，不用主号。
- 卸载：先双击 `停止.bat`，再删除整个安装目录即可；不写注册表、不装系统服务。
